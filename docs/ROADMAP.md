# Roadmap

Already available: persistent wiki, typed graph, bounded acquisition, explicit reading coverage, source-linked answers, manual-edit preservation and structural lint.

Near-term contribution areas (not promises of implemented capability):

- English UI and configurable output language.
- Better onboarding for arbitrary topics and model-provider compatibility tests.
- More import formats and a verified Zotero handoff.
- Dedicated OpenReview / ACL collectors with coverage tests.
- Citation chasing validation before enabling it by default.
- A reviewed research_agent handoff format beyond manual Markdown sharing.
- Human review states and richer reconciliation of updated source pages.

Novelty verification, autonomous experiments and universal full-paper understanding are outside the current release's claims.
